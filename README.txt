PROCESSMASTER v1

Zum Testen index.html in Chrome öffnen. Für die Installation als PWA alle Dateien zusammen auf einem HTTPS-Webhost (z. B. GitHub Pages) bereitstellen und in Chrome 'Zum Startbildschirm hinzufügen' wählen.

Die Daten werden nur lokal im jeweiligen Browser gespeichert. Regelmäßig unter 'Daten' exportieren.

Diese Version enthält 8 Grundlagenlektionen, 8 Quizfragen, ein Prozesslabor, eine Wissensbank und einen Business-Case-Rechner. Die weiteren Module des 16-Wochen-Studiums sind noch nicht enthalten. Offene Aufgaben werden nicht automatisch fachlich bewertet.

Keine vertraulichen Unternehmens- oder Patientendaten eingeben.
